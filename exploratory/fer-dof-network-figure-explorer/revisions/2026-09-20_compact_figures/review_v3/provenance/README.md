## Calculation lineage and the retained-code gap

**Family enrichment and context nominations.** The upstream calculation is `revisions/2026-09-08_routeA_execution/q04_network/scripts/02_repair_network_annotations.R`. It reads saved network scores and original nomination tables, repairs DE annotations without changing score columns, reconstructs the top-100 and pooled 10%/90% rank-tail selection, and calculates family enrichment. The chosen family output uses PlantTFDB family membership and 1,292 TFs scored in both genotypes in at least one context. It uses a one-sided Fisher enrichment P value, two-sided 95% Fisher confidence interval, and BH correction across the 55 families in each genotype-specific comparison. The later input-preparation script selects this existing universe, and `B/top10_family_prototypes/make_top10.R` chooses the displayed ten families. The displayed family effects are not tests of genotype differences.

The matrix input preparation is `.living/tasks/fer-fig6-brainstorm-2026-09-20/outputs/claude-science/code/prepare_inputs.py`. Its `dof_context_status.csv` feeds `B/celltype_prototypes/make_celltype_summary.R`, which aggregates by gene and cell identity. The denominator is developmental zones with scores in both genotypes for the same gene and identity. No cell-type-only network was fitted.

**Overlap provenance gap.** `B/network_audit.md` records the original reconstruction inputs: Q04 `WT_specific_TF_DE_repaired.csv`, `fer4_specific_TF_DE_repaired.csv`, `DOF_family_definition_comparison.csv`, and pinned public `Differential_expression_analysis/outputs/sig_de_fil.csv`. It records the 37-DOF, 512-GRN-TF and 5,466-DEG sets and all seven disjoint counts. A retained standalone script that first wrote `fig6_dof_membership.csv` and `fig6_full_intersections.csv` was not located in the inspected project and task code. This is a source-code preservation gap, not evidence that the saved counts are wrong. The evidence-bar and UpSet plotting scripts can reproduce and assert their displayed counts from the retained tables, but those assertions are not an independent rerun of the initial reconstruction.

**Networks.** `D/inventory/build_inventory.R` extracts the ten tested DOFs from Q04 retained edge tables and adds tissue-map and edge/score flags. `D/annotations/01_annotate_dof_targets.R` derives GO annotations and symbol mappings using the frozen `reference/gene_ontology/go-basic.obo` and `ARATH-mod.gaf.gz`. The overview plots use that output for symbol normalization, then explicitly select the symbol-family pattern `^(IAA[0-9]|SAUR[0-9]|GH3[.]|TAA[0-9]|TAR[0-9]|YUC[0-9])`. This is a restricted family display rule, not a claim to include all auxin genes or a GO enrichment test.

The all-context union retains every selected source-target pair observed anywhere in the saved data and flags support in the seven-fit reference versus additional excluded fits. It considers all 44 context labels and 87 genotype-context exports; the selected target-family links occur in 43 labels and 83 genotype-contexts. The vascular subset is elongating phloem-pole pericycle, xylem-pole pericycle and procambium. Pole-pericycle contexts belong to the pericycle fit, not the separately excluded phloem/xylem fits. Neither graph is a single jointly fitted network or evidence of intercellular transport, and neither pools edge coefficients or gene-expression effects.

## Reproduction levels and commands

**1. Recreate figures from retained inputs.** Each row of `INPUT_OUTPUT_CODE.csv` contains exact plotting/grouping commands. Those scripts write beside themselves, so run them in an isolated copy of the project if the existing figures must remain untouched. They were not executed during this provenance task. Example for the v2 forest:

```sh

```

The all-context network additionally requires `build_all_context_union.R` before its plotting script. The vascular plotting script performs its small subset/union calculation itself and also writes the seven-fit overview used as the all-context reference. UpSet invokes its SVG helper automatically.

**2. Recalculate summaries from saved network outputs.** The Q04 script, input-preparation script, cell-type summary script, target inventory and annotation scripts are listed separately from plotting code. They require their original inputs and directory structure. Q04 uses absolute Resnick source paths and takes its output root as an argument, so it is not a portable one-command local rebuild. Recalculating these tables can overwrite downstream outputs and has not been performed by this task.

**3. Rebuild or reconcile the underlying networks.** The original CellOracle script performs imputation and inference (`get_links`, alpha 10), filtering (p < 0.01, absolute coefficient, 20,000 links), score calculation and export. This is distinct from levels 1 and 2. It takes a tissue-array index and uses a common remote working directory. The committed tissue dictionary has endodermis commented out, and the exact historical execution environment/launch record is incomplete. The current Resnick CellOracle 0.20.0 snapshot in `V2/audit_response/` is not proof of the historical version. Therefore neither an exact raw-model rebuild nor a corrected analysis is certified by these plotting commands.
