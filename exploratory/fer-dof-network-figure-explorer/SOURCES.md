# Sources, code and reproduction limits

**Prototype; not yet carefully vetted.** This package preserves a bounded collection of existing figure outputs, selected source tables and code references. It is not a completed raw-analysis release.

## Current panel map

The [complete input/output/code inventory](revisions/2026-09-20_compact_figures/review_v7/provenance/CURRENT_INPUT_OUTPUT_CODE.csv) records six panel types, calculation code, plotting code, exact inputs, outputs, dimensions, commands and interpretation limits. Each panel's PDF, SVG and PNG is included. A retains the v5 forest, B and C retain v6, D uses v7, and the supporting vascular network and alternative UpSet retain their recorded source versions.

All seven unique immediate plotting input tables listed across the six panels are included. In particular, panel C reads only [celltype_summary_all37.csv](revisions/2026-09-20_fig6_brainstorm/celltype_prototypes/celltype_summary_all37.csv); it does not read the TF-family enrichment table. Network-source context rows are in the [all-context edge table](revisions/2026-09-20_compact_figures/review_v2/all_contexts/all_contexts_as_exported_source_context_edges.csv). Panel D retains the [original union table](revisions/2026-09-20_compact_figures/review_v2/all_contexts/all_contexts_as_exported_union_edges.csv).

The [membership reconstruction R script](revisions/2026-09-20_compact_figures/review_v5/provenance/reconstruct_memberships.R), all nine of its recorded table inputs and its [comparison report](revisions/2026-09-20_compact_figures/review_v5/provenance/README.md) are included. This independently reconstructs the gene identities and flags and all seven exclusive overlap counts; 17 display-symbol differences are preserved. It does not claim recovery of the historical generator or correction of network inputs.

## Reproduction limits

**Saved-table plotting:** the current R plotting scripts and immediate input tables are included. Start with the commands and dependencies in the current inventory. The R dependencies are ggplot2, cowplot, colorspace, svglite and data.table. Forest, matrix and v7 network rendering call Quartz PDF and use Arial, so their current redraw path is macOS-specific. SVG helpers require Python lxml. The UpSet script expects an executable named `python`; UpSet and evidence-bar scripts invoke `shasum`. Original proof generators use hardcoded macOS font locations. Some helper scripts carry machine-specific paths or assumptions. Inspect them before running in an isolated working copy; scripts may write alongside their own files.

The v7 [finalize_and_validate.py](revisions/2026-09-20_compact_figures/review_v7/networks/finalize_and_validate.py) is an additional post-render helper, omitted from the frozen panel inventory but included here. It requires Poppler tools. Historical v5/v6 validation helpers may require earlier reference CSVs that are not all included; they are optional reference checks, not prerequisites for reading the current figures. The coordinator's separate share-PDF script uses web links and does not alter original source PDFs.

**Summary reconstruction:** membership reconstruction uses the recorded nomination, family and DE tables. Some checks inspect the pinned source checkout's Git revision; the full checkout and its Git metadata are excluded. Historical code-reference dependency manifests identify further inputs outside this package. Preserved code is not silently rewritten to make these checks disappear.

**Raw network rebuilding:** this package does not include the large Seurat/H5AD/link objects, the full public source checkout, all upstream tables, historical execution environment or every remote dependency. Plot regeneration does not reproduce network inference, reconcile endodermal scores or fix phloem/xylem feature selection. Those require a separately reviewed analysis step using the underlying sources.

Original source bytes remain unchanged, apart from prototype headers already present in the v6 code-reference snapshots. New package navigation, the assembly helper and local verification helper are separate from copied scientific source files. No credentials, full manuscript, private task prompts, complete session histories or raw HPC objects are included.
