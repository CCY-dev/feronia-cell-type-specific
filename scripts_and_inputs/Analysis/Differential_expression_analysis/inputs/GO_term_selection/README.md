# Selected GO terms (proposed Extended Data Fig. 3)

The two spreadsheets mark the 15 terms selected for display (`Selected?` = yes) among the GO tables of up- and down-regulated genes. They are read by `scripts/20260317_Feronia_GO_terms_plot_new_integrated_seu3.R`.

Note (20 Oct 2026): the selections were made on an earlier version of the GO tables; their values differ from the current tables in `../../outputs/GO/`. Four selected terms do not occur in the current tables and are dropped by the plotting script: "cellular response to ethylene stimulus" (up), and "cell differentiation", "cell morphogenesis" and "hydrogen peroxide metabolic process" (down).
